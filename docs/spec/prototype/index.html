How to use
  • Mouse: start dragging a file, tap ⇧ convert, ⌘ tools, or ⌃ actions. Let go of the key, keep dragging, and drop on a petal.
  • Keyboard: Tab to a file, press Return. Use arrows to move, Return to apply, Esc to cancel, and ⇧ ⌘ ⌃ to switch wheels. ⌃⌥Space opens the wheel for the selected file.
  • Multiple files: ⌘-click to select several, then drag one of them.
  • Touch: hold a file for half a second, then drag to convert.
Simulation only: no real files are read or written. Formats and tools follow the capability matrix in the spec.

Drag a file, then tap Shift for conversions, Command for file tools, or Control for file actions. The wheel stays open until you drop. Or focus a file and press Return to open the conversion wheel. Use the arrow keys to choose, Return to apply, and Escape to cancel.
